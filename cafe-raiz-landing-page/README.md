# CaféRaíz Landing Page

## Overview
CaféRaíz is a landing page designed to showcase the offerings of the CaféRaíz company. The page features a clean and modern design, with sections dedicated to the company's menu, about information, and a contact form for inquiries.

## Project Structure
```
cafe-raiz-landing-page
├── css
│   └── style.css        # Styles for the landing page
├── index.html           # Main landing page
├── menu.html            # Secondary page for menu details
└── README.md            # Project documentation
```

## Setup Instructions
1. Clone the repository to your local machine.
2. Open the `index.html` file in your web browser to view the landing page.
3. Navigate to `menu.html` for additional menu details.

## Features
- Fixed navigation bar with links to different sections.
- Hero section displaying the company name.
- Menu section with product cards.
- About Us section with company information.
- Contact form for user inquiries.
- Responsive design with media queries for mobile devices.

## Technologies Used
- HTML5
- CSS3
- Flexbox/Grid layout for responsive design

## Additional Information
Feel free to customize the styles in `css/style.css` to match your branding preferences.
